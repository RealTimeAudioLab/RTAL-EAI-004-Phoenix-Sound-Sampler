PROJECT PHOENIX v0.7.19c - ECHO FIX

Changes:
- Default global polyphony fixed at 16 voices.
- PHX_VOICE_COUNT now accepts values from 1 to 24 for later tests.
- Echo tail continues after the last polyphonic voice ends.
- Short samples now produce delayed repeats even when their sample duration is shorter than ECHO DELAY.
- Echo tail also works with FEEDBACK=0 (one delayed repeat).
- Removed an accidental duplicate processEcho declaration in the transport path.

Test:
1. Set SEND S1 = 100%.
2. Set MIX = 50%.
3. Set DELAY = 250 ms and FEEDBACK = 35%.
4. Trigger a short sample in slot 1.
5. The dry sound must be followed by audible repeats.
6. Set FEEDBACK = 0%. One delayed repeat must still be audible.
