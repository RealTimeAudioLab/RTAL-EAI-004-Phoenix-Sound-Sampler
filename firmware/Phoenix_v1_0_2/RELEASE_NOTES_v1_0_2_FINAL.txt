Project Phoenix v1.0.2 FINAL - Robust Bank-Load Watchdog Fix

Baseline
--------
Direct successor to v1.0.1 / v1.0.0 FINAL. Audio DSP, voice allocation, sequencer timing, MIDI semantics, bank format and multisample format are unchanged.

Problem
-------
A large multisample demo bank still triggered the ESP32-S3 task watchdog on Core 0 during BANK_LOAD. The watchdog identified IDLE0 as starved while PhoenixControl was running. v1.0.1 changed the per-sample conversion yield from delay(0) to delay(1), but this did not guarantee a full scheduler slot for IDLE0.

Fix
---
- Multisample WAV conversion now uses vTaskDelay(pdMS_TO_TICKS(2)) every 1024 output frames.
- MULTISAMPLE.CFG parsing yields 2 ms every eight parsed lines.
- A 2 ms yield is inserted between multisample clear/load stages.
- Base SLOTn.WAV bank loading also uses a 2 ms cooperative sleep per 2 KiB read chunk.
- Bank load now prints explicit AUDIO / PATTERNS / SONG phase markers.
- Each multisample WAV prints begin/ok diagnostics including slot/group/layer/RR and frame count.

Compatibility
-------------
BANK_VERSION=15
MULTISAMPLE_VERSION=10
32 kHz / 128 frames / 12 voices
No intended realtime audio or sequencer behavior change.
